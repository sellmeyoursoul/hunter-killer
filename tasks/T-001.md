## Contract
1. New helper, place it directly above `_report`, with a `##` doc comment (purpose, `[param samples]`, return value, `Example:`):
```
static func roster_frame_stats(samples: PackedFloat32Array) -> Dictionary
```
   Returns `{"frames": int, "mean_ms": float, "p50_ms": float, "p95_ms": float, "max_ms": float}`. Percentiles use nearest rank on a sorted **copy** (the input is not modified): `rank = clampi(int(ceil(q * float(n))) - 1, 0, n - 1)`, `q` = 0.5 / 0.95 / 1.0 for p50 / p95 / max. Empty input returns `frames` 0 and all four floats `0.0`.
2. New private helper, place it directly above `roster_frame_stats`, with a `##` doc comment:
```
func _nav_sum_ms_all() -> float
```
   Returns the sum, over every entry of `_NavTiming.snapshot_all()`, of `float((snap["total"] as Dictionary)["sum_ms"])` (lifetime nav ms of all creatures; 0.0 when none).
3. In `_run`, around the measured loop (the `for _i in _frames:` that follows `_NavTiming.reset_all()`):
   - before the loop: `var frame_ms := PackedFloat32Array()` and `var prev_sum := _nav_sum_ms_all()`;
   - in the loop, directly after `await physics_frame` and **before** `_restart_if_round_ended()`: `var now_sum := _nav_sum_ms_all()`, append `maxf(0.0, now_sum - prev_sum)` to `frame_ms`, then `prev_sum = now_sum`;
   - call `_report(wall_s, _restarts - started_restarts, frame_ms)`.
   Exactly one sample per measured frame, so `frame_ms.size() == _frames`. The warmup loop is not touched.
4. `_report` gets a third parameter `frame_ms: PackedFloat32Array` (signature `func _report(wall_s: float, restarts_in_window: int, frame_ms: PackedFloat32Array) -> void:`). Directly after the existing `POOLED c ...` print, add one print of exactly this format (two leading spaces; `%` formatting as in the neighbouring prints):
```
  ROSTER per-frame total (all frames) n=%d mean=%.4f p50=%.4f p95=%.4f max=%.4f ms | B_nav=%.1f ms -> p95 %s B_nav
```
   where `n` = `frames`, the four floats come from `roster_frame_stats(frame_ms)`, `B_nav` is `_B_NAV_MS`, and the final `%s` is `"<="` when `p95_ms <= _B_NAV_MS` and `">"` otherwise. Use `print`, like the other lines in this tool (it is a CLI tool, not game code).
